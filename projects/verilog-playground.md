## Project overview

This project evolved through 3 major versions created to improve Computer Organization and Architecture (COA) classes and make digital design practice more accessible.

## Version 1: FPGA Board Simulator

The first version was the **FPGA Board Simulator** (2018), the most adopted one and the version with the most GitHub stars.

Before it, students depended on physical FPGA boards in the college laboratory. The simulator removed this physical lab bottleneck and reduced compilation time from over 3 minutes to about 7 seconds, enabling faster test-and-fix loops.

Professor **Elmar Melcher** was the top contributor in the repository, with support from other students.

## Version 2: Learn SystemVerilog

During the pandemic, I built **Learn SystemVerilog** to run directly in the browser.

This simplified setup and allowed students, including low-income students using mobile devices, to practice without requiring local installation. This work became my undergraduate final project (TCC), which received a **10/10** score.

## Version 3: Verilog Playground

The final and most professional version is **Verilog Playground**.

It was deployed with **AWS CDK**, and simulation runs use **ReCAPTCHA** verification so users can run simulations without account login while still protecting the service.

This version was recognized as a notable project by **veripool.org**.

## Impact

- Removed dependency on physical lab board availability.
- Reduced compilation turnaround from 3+ minutes to ~7 seconds.
- Enabled browser-based learning and broader device accessibility.
- Improved teaching workflows for professors in COA courses.
